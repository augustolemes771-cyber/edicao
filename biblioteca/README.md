# Biblioteca

Tudo que pode ser reaproveitado entre vídeos. O painel (`npm run painel`) lista isto automaticamente:

- `src/pecas/` peças e efeitos; `src/pecas/tres/` modelos 3D; `scripts/blender/` modelos feitos no Blender
- `src/projetos/` vídeos prontos, que servem de template
- `public/sfx/`, `public/fontes/`
- `biblioteca/itens/*.json` itens registrados pelo Claude: `{"nome","tipo","descricao","arquivo","exemplo"}`
